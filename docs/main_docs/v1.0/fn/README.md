# Functional Specifications (v1.0)

File mẫu riêng: [Functional spec template](../../../templates/functional-spec.md). Bản đề xuất chưa duyệt lưu trong task, chưa phải spec canonical.

Thư mục này chứa toàn bộ các đặc tả chức năng nghiệp vụ (Functional Specs) của dự án ở phiên bản active `v1.0`.

## Cấu Trúc Đặt Tên File
- Mỗi tính năng/module có một file riêng: `<module-name>.md` (ví dụ: `auth.md`, `billing.md`, `study-session.md`).

## Nội Dung Một Functional Spec

Dùng [Functional spec template](../../../templates/functional-spec.md) làm mẫu đầy đủ. Spec cần mô tả business context, user flows, rules/invariants, edge cases/error paths, observable acceptance criteria và trạng thái/approval; README này chỉ hướng dẫn cấu trúc.
