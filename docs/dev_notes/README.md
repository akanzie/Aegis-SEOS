# Developer Notes & Scratchpad

Thư mục này là khu vực nháp (sandbox) dành cho Developer và AI Agent:
- Ghi chép cá nhân tạm thời trong quá trình nghiên cứu.
- Các đoạn code thử nghiệm (spikes / POCs).
- Lược đồ phân tích nhanh trước khi đưa vào tài liệu chính thức.

> **Lưu ý**: Các tài liệu có giá trị lâu dài nên được tinh chỉnh và chuyển sang `docs/architecture/`, `docs/decisions/` hoặc `docs/project-memory/`.
